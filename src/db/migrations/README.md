# SQL migration files managed by node-pg-migrate will live here.
# Each migration file follows the naming convention:
#   <timestamp>_<description>.sql
# Example:
#   1724000000000_create_departments_and_countries.sql
#
# Migrations are created via:
#   npm run migrate:create -- <description>
#
# Applied via:
#   npm run migrate
#
# Rolled back via:
#   npm run migrate:down
